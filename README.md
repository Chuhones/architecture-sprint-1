# Задание 1

Поставлена задача разбить существующий монолитный фронтенд на микрофронтенды. 

# Выбор инструментов

В качестве фреймворка для создания микрофронтендов выберем 'Webpack Module Federation'. Он относительно простой в понимании процесса компоновки отдельных МФ и их взаимодействия. В то же время не требует привязки к одностраничному исполнению проекта, в отличие от 'Single SPA'. Это отчасти может дать больше возможностей маневра для расширения проекта небольшой командой без богатого опыта использования микрофронтендов.

# Планирование изменений

Выделим бизнес функции приложения:
 - Основная функция - **работа с альбомом**. Добавление, удаление, управление лайками.
 - **Авторизация** - возможность зарегистрироваться и авторизоваться
 - **Профиль пользователя** - отображение карточки пользователя и возможность ее изменить

В соответствии с этим выделим микрофронтенды
 - **mfe-album** - добавление и удаление фотографий, управление лайками
 - **mfe-auth** - авторизация и регистрация
 - **mfe-profile** - работа с профилем пользователя
 - **mfe-base** - базовый микрофронтенд, который задает окружение и основу для композиции остальных микрофронтендов
 - **microfrontend-lib** - библиотека, которая предназначена для выделения общих компонентов и их переиспользования в остальных микрофронтендах

Каждый микрофронтенд может быть вынесен в отдельный репозиторий SCM и разрабатываться независимо. **microfrontend-lib** вероятно должен на стадии сборки импортироваться в остальные МФ.
